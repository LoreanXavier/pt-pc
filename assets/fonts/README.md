# Bundled UI fonts

Google Noto fonts, SIL Open Font License 1.1. Private process registration only; no Windows font installation. Used for added Turkish, Simplified Chinese, Arabic, Russian, Ukrainian, Czech and Polish menus/subtitles. Original game fonts remain for original languages. Arabic uses Noto Kufi Arabic in the menus and Noto Naskh Arabic in the subtitles.

Handwriting fonts (SIL Open Font License 1.1) for the survival night's notices, in a hand like the game's subliminal strings (`text_sub*_alp`, a quick pen's print): Marck Script (Latin, Cyrillic), Yomogi (Japanese), Long Cang (Simplified Chinese), Aref Ruqaa (Arabic). The build copies the OFL notices to `licenses/` as well.
