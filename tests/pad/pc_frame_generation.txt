# Frame generation on the PC settings page, in a window, with a virtual DualShock 4: the row is greyed while the upscaler
# is off, FSR enables it, On replaces the swapchain with the FSR 3 interpolation swapchain, a smaller window size recreates
# that swapchain, Off returns to the plain one, and the upscaler set to Off greys the row again. pt.log names each swapchain
# change ("frame generation: ..."); screenshots fg1 to fg3 go to the working folder.
# Start with upscaler = off and frame_generation = 0 in the [upscaling] section of <pt.ini>; keep the window from taking
# the focus and the audio silent:
# SDL_WINDOW_ACTIVATE_WHEN_SHOWN=0 SDL_AUDIO_DRIVER=dummy pt.exe --virtual-pads --no-save --settings <pt.ini>
#   --start-floor f010 --frames 6000 --input-script tests/pad/pc_frame_generation.txt
# Buttons are pressed and released with sbutton and swait, which count game ticks, so the presses do not depend on the
# frame rate as long as it stays above the tick rate (60 per second): a press within one frame's ticks is never seen.
